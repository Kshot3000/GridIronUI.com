How it works. Cash lineups maximize projection minus a volatility penalty (high floors win). GPP lineups maximize ceiling with NFL QB + 2 same-team pass-catcher stacks. The optional game-stack bring-back (NFL tournaments) seats one opposing-team pass-catcher alongside every QB stack — shootout upside on both sides. Then hill-climbing swaps improve every lineup until no single swap helps. 🔒 Locks appear in every lineup (and ignore the exposure cap); 🚫 exclusions appear in none. The exposure summary under your results shows each player's share of lineups, so you can spot when you're overweight on a play. A 🌬️ game-conditions strip shows real stadium forecasts (wind, rain, roof status) for the NFL games your pool plays in — wind moves totals and the passing game, so check it before you lock pass-catchers and kickers. The pool table has a Value column (projected points per $1k of salary, ★ marks the top-3) plus a search box, position filter and clickable column sorting — handy once an imported CSV puts 100+ players in the pool. No AI, no magic — just math you can audit. Export CSV writes the sites' bulk-uploader cell format — DraftKings gets Name (ID) using the player IDs captured from your salary export, FanDuel gets the FD player ID — so generated lineups drop straight into the site's uploader instead of being retyped. Players with no captured ID export as plain names; always sanity-check one lineup against the site's Download Template for your contest before uploading.
